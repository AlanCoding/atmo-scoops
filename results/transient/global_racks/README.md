# Numerical pilot, not an optimized design

This partial 52-coordinate pilot preceded the 55-coordinate search in
`../rack_optimization`. It has no feasible solution and includes unresolved
integrations. Do not quote its diagnostic payoff as a recurring cycle.

The top-level `low_re_trial.json.gz` is an earlier solver/thermal pilot, not the
final paired-bank model. `vent_seed.json.gz` records the compact-bank numerical
seed with shorter vent timing; it fails propellant closure. Their inputs are
embedded; these files are not design recommendations.
