# Numerical result retention

Commit named reference inputs, solver manifests and termination reports, compact
comparison summaries, and selected/validation trajectories used by reports.
Preserve historical design evidence under meaningful names.

Per-evaluation `eval_*.json`, worker `task_*.json`, and anonymous
`trajectory_*.json[.gz]` files under this directory are local search caches,
ignored by Git. They can be regenerated by the recorded search command. Git
cleanup removes them from the current index, not from local disk or old commits.
A fresh checkout reruns evaluations instead of depending on those caches.

Numbered historical candidates that published studies directly identify remain
versioned; they are not covered by a blanket JSON or results-directory exclusion.
For new selected results, prefer descriptive names such as `selected_refined`.
